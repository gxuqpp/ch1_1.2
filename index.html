教材出处、计算方法与适用条件

公式与符号

教材给出乘用车总长 Lₐ = L/C，并说明 C 为比例系数。由此得 C = L/Lₐ、L = C·Lₐ。输入和输出的长度统一使用 mm，图中坐标刻度使用 m。

前、后悬总长 S = Lₐ − L = (1 − C)Lₐ。为绘制分段尺寸，额外给定前悬占两悬总长的比例 q：Lꜰ = qS，Lʀ = (1 − q)S。q 是本工具的辅助示意参数；它不属于教材给出的 C 关系式。

固定总车长时，L 随 C 线性增加；固定轴距时，Lₐ 随 C 按反比例减小。固定 C 时，L 与 Lₐ 成正比。

教材页码与参考范围

《汽车设计》第5版，印刷第18页；本地 PDF 的第30页。一般 C = 0.52～0.66；发动机前置前轮驱动汽车为 0.62～0.66，发动机前置后轮驱动汽车约为 0.52～0.56。

  • 本工具讨论乘用车尺寸比例，数值为几何计算与教学示例。
  • 此关系不能单独确定前、后悬各自的长度，也不直接计算车内空间、转弯直径或通过性。
  • 教材经验区间用于初步选型参考；本页不作车辆法规尺寸或具体车型可行性校核。
  • 图中保持各长度段的比例关系。固定车长模式固定车身绘图长度；固定轴距模式固定两轴绘图间距。两种模式的显示比例尺分别确定。
